2. Network construction

Step 1 – Load feature table (raw reads) and filter data

Not done for this dataset as it is already aggregated to the species level, leaving 453 taxa (total read count at species level) (which is fine for the network to handle). This is one option of reducing the amount of nodes in the dataset.

How you filter data is an important question to consider. One option is to remove low-abundance taxa or taxa that only occur in a small proportion of your experimental units. E.g. if taxa are only present in 5% of your 4 bacterial communities from seawater condition, it is likely that they don’t play an important role in your co-occurrence network (as their chance to ‘co-occur’ is quite small). How many nodes a network can handle will depend on the dataset (the variation in data). There’s no hard and fast number for this, but around 200-800 nodes generally works fine.

Step 2 – Construt network for the full dataset

Below is the code to construct the network. This step is heavy on computational memory and very slow. So I have constructed networks in advance and loaded it later on. See https://github.com/zdk123/SpiecEasi for more details. This input for SPIEC-EASI is a counts table. The normalization and tranformation is done by the function. More information on SPIEC-EASI.

  • Ingredients

  • method: can be ‘mb’ (Neighborhood selection) or ‘glasso’ (inverse covariance selection)

  • nlambda: tells the model how many different lambda values to try (how many ways to wire each node pair in the network). This essentially determines how complex your network is. A value between 20-120 is fine. Higher nlambda = more computational time and very high nlambda (> 150 or so) risks over fitting.

  • lambda.min.ratio: determines/constrains the range of nlambda values (i.e. 1e-2 means that the smallest lambda value is 1% of the largest)

  • pulsar.params: rep.num = number of times the network is re-sampled (bootstrapped), thresh: sets the stability threshold for edges in the network. 0.05 means that an edge must occur in 5% of the bootstrapped samples to be considered in the final model.

  • sel.criterion: model sparseness is inferred using the Stability Approach to Regularization Selection (StARS), which involves random sub-sampling of the data set to find a network with low variability in the selected set of edges. character string specifying criterion/method for model selection. Accepts ‘stars’ [default], ‘bstars’ (Bounded StARS)

  • The goal is to have a stable network >> target stability threshold (getStability) should be very close to 0.05. To improve the stability score, you can adjust:

  • nlambda

  • lambda.min.ratio

  • sel.criterion

## Parallel multicore ##

3. Network validation (quality & robustness)

SpiecEasi networks require three levels of validation before ecological interpretation:

Level What it tests Key metric
1. Internal stability Did the StARS/bSTARS selection converge? getStability() ≈ 0.05
2. Non-randomness Is the observed network different from random? Compare topology to null ensemble
3. Small-world topology Is the network biologically plausible? σ = (C/C_rand) / (L/L_rand) > 1

Step 2 – Permutation to generate null ensemble

Permutation has been run before, so we just need to load it in the next step.

# ── Generate null model ensemble in R ────────────────────────────────────────
# Method: degree-preserving edge rewiring (Maslov-Sneppen algorithm)
# This preserves the degree sequence of each node while randomising
# which nodes are connected — the standard null model for ecological networks
# igraph contains a function to rewire networks. We will rewire 100x edges while preserving the original degree distribution. 10x permutations should give an idea of the variation in centralities. For each of the permutations, we can generate a similar dataframe as the centralities dataframe generated for the original graph.


n_nulls  <- 999    # number of null models — 999 is standard in the literature
niter    <- 100    # rewiring iterations per edge (higher = more randomised)
                   # recommended: 100× number of edges

set.seed(42)

cat(glue::glue("
── Generating {n_nulls} null models ─────────────────────
  Method : degree-preserving edge rewiring
  Network: {vcount(ig_network_full_filtered)} nodes, {ecount(ig_network_full_filtered)} edges
  niter  : {niter} rewiring attempts per edge
  This will take several minutes...
──────────────────────────────────────────────────────
\n"))

# ── Helper: generate one null graph ──────────────────────────────────────────
make_null_graph <- function(g, niter) {
  # rewire() shuffles edges while preserving degree sequence
  g_null <- rewire(g, with = keeping_degseq(niter = niter * ecount(g))) # 204,000 attempts per edge — 10× edges is commonly used in ecology papers
  # simplify removes any self-loops or multi-edges introduced by rewiring
  g_null <- igraph::simplify(g_null)    
  g_null
}

# ── Generate the ensemble with progress reporting ─────────────────────────────
# Use a simple loop so progress is visible
null_graph_list <- vector("list", n_nulls)

for (i in seq_len(n_nulls)) {
  null_graph_list[[i]] <- make_null_graph(ig_network_full_filtered, niter)
  if (i %% 100 == 0) cat("  Generated", i, "/", n_nulls, "null models\n")

# ── Compute topology metrics for each null graph ──────────────────────────────
compute_null_metrics <- function(g) {
  list(
    transitivity  = transitivity(g, type = "average"),
    mean_path     = tryCatch(
                      mean_distance(g, directed = FALSE),
                      error = function(e) NA_real_),
    modularity    = modularity(cluster_louvain(g)),
    mean_between  = mean(betweenness(g, normalized = TRUE))
  )
}


cat("Computing topology for", length(null_graph_list), "null models...\n")

# ── 6. Z-scores: how many SDs is the observed from the null mean? ─────────────
z_scores <- null_df %>%
  summarise(across(where(is.numeric), list(mean = mean, sd = sd), na.rm = TRUE)) %>%
  pivot_longer(everything(),
               names_to  = c("metric", ".value"),
               names_sep = "_(?=[^_]+$)") %>%
  left_join(
    obs_df %>% pivot_longer(-type, names_to = "metric", values_to = "obs"),
    by = "metric"
  ) %>%
  mutate(
    z        = (obs - mean) / sd,
    p_approx = 2 * pnorm(-abs(z)),   # two-tailed approximate p-value
    sig      = case_when(
      p_approx < 0.001 ~ "***",
      p_approx < 0.01  ~ "**",
      p_approx < 0.05  ~ "*",
      TRUE              ~ "ns"
    )
  )
